# 📦 المرحلة 5: تحديث الحزم الخارجية

## 🎯 الهدف
تحديث جميع الحزم الخارجية لتكون متوافقة مع Laravel 11.

---

| الحزمة | الإصدار الحالي | الإصدار المطلوب | الحالة |

| `laravel/framework` | ^8.75 | ^11.0 | 🔴 يحتاج تحديث |
| `laravel/sanctum` | ^2.11 | ^4.0 | 🔴 يحتاج تحديث |

## 1️⃣ الحزم التي يجب إزالتها

### أ) `fruitcake/laravel-cors`
**السبب:** مدمج في Laravel 9+

```powershell
composer remove fruitcake/laravel-cors
```

### ب) `facade/ignition`
**السبب:** تم استبداله بـ `spatie/laravel-ignition`

```powershell
composer remove facade/ignition
```

### ج) `laravelcollective/html`
**السبب:** غير متوافق مع Laravel 11 (تم إزالته مسبقاً)

```powershell
# تم إزالته مسبقاً ✅
```

## 2️⃣ الحزم التي يجب إضافتها

### أ) `spatie/laravel-ignition`
**السبب:** بديل لـ `facade/ignition`

```powershell
composer require spatie/laravel-ignition --dev
```

### ب) `maatwebsite/excel` (إذا لم يكن مثبتاً)
**السبب:** للتصدير إلى Excel

```powershell
composer require maatwebsite/excel
```

**ملاحظة:** يتطلب PHP extensions:
- `ext-gd`
- `ext-zip`

لتفعيلها في Laragon:
1. افتح `php.ini`
2. أزل `;` من أمام:
   ```ini
   extension=gd
   extension=zip
   ```
3. أعد تشغيل Laragon

## 4️⃣ تنفيذ التحديث الشامل

```powershell
# الخطوة 1: نسخ composer.json الجديد

# الخطوة 2: حذف vendor و composer.lock
Remove-Item -Recurse -Force vendor -ErrorAction SilentlyContinue
Remove-Item composer.lock -ErrorAction SilentlyContinue

# الخطوة 3: تثبيت الحزم
composer install

# الخطوة 4: إذا حدثت أخطاء
composer update --with-all-dependencies --ignore-platform-reqs

# الخطوة 5: نشر ملفات الحزم
php artisan vendor:publish --provider="Maatwebsite\Excel\ExcelServiceProvider" --tag=config
```
