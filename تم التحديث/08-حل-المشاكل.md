## 1️⃣ مشاكل Composer

### المشكلة: Your requirements could not be resolved
```
Your requirements could not be resolved to an installable set of packages.
```

**الحل:**
```powershell
# حذف vendor و lock
Remove-Item -Recurse -Force vendor -ErrorAction SilentlyContinue
Remove-Item composer.lock -ErrorAction SilentlyContinue

# تحديث مع تجاهل متطلبات المنصة
composer update --with-all-dependencies --ignore-platform-reqs
```

---

### المشكلة: Package not found
```
Package "package-name" not found
```

**الحل:**
```powershell
# مسح cache الـ composer
composer clear-cache

# تحديث قائمة الحزم
composer update
```

---

### المشكلة: Memory limit exceeded
```
Allowed memory size exhausted
```

**الحل:**
```powershell
# زيادة الذاكرة مؤقتاً
php -d memory_limit=-1 composer update
```

## 2️⃣ مشاكل Middleware

### المشكلة: Target class [middleware] does not exist
```
Target class [auth] does not exist.
```

**الحل:**
تأكد من إضافة الـ middleware في `bootstrap/app.php`:
```php
$middleware->alias([
    'auth' => \App\Http\Middleware\Authenticate::class,
    // أضف باقي الـ middleware
]);
```

---

### المشكلة: Middleware group not found
```
Middleware group [web] not found
```

**الحل:**
```php
// في bootstrap/app.php
$middleware->web(append: [
    \App\Http\Middleware\EncryptCookies::class,
    // ...
]);
```

---

### المشكلة: Class not found for custom middleware
```
Class 'App\Http\Middleware\SuperAdminMiddleware' not found
```

**الحل:**
1. تأكد من وجود الملف في المسار الصحيح
2. شغّل: `composer dump-autoload`

---

## 3️⃣ مشاكل Routes

### المشكلة: Route [name] not defined
```
Route [dashboard] not defined.
```

**الحل:**
1. تأكد من أن الـ route معرّف في `routes/web.php`
2. تأكد من أن الـ routes محملة في `bootstrap/app.php`:
```php
->withRouting(
    web: __DIR__.'/../routes/web.php',
)
```
3. امسح cache الـ routes:
```powershell
php artisan route:clear
```

---

### المشكلة: Controller not found
```
Target class [App\Http\Controllers\SomeController] does not exist.
```

**الحل:**
1. تأكد من وجود الـ controller
2. تأكد من الـ namespace صحيح
3. شغّل: `composer dump-autoload`

---

### المشكلة: Method not allowed
```
The GET method is not supported for route
```

**الحل:**
تأكد من أن الـ form يستخدم الـ method الصحيح:
```html
<form method="POST" action="{{ route('...') }}">
    @csrf
    @method('PUT')  <!-- إذا كان PUT -->
</form>
```

## 4️⃣ مشاكل Views

### المشكلة: View not found
```
View [home] not found.
```

**الحل:**
1. تأكد من وجود الملف في `resources/views/`
2. امسح cache الـ views:
```powershell
php artisan view:clear
```

---

### المشكلة: Undefined variable
```
Undefined variable $variable
```

**الحل:**
1. تأكد من تمرير المتغير من الـ controller:
```php
return view('page', ['variable' => $value]);
```
2. أو استخدم null-safe:
```php
{{ $variable ?? 'default' }}
```

---

### المشكلة: CSRF token mismatch
```
419 | Page Expired
```

**الحل:**
1. تأكد من وجود `@csrf` في الـ form
2. تأكد من أن VerifyCsrfToken middleware مضاف
3. امسح cache الـ session:
```powershell
php artisan session:clear
```

---

## 5️⃣ مشاكل Database

### المشكلة: Connection refused
```
SQLSTATE[HY000] [2002] Connection refused
```

**الحل:**
1. تأكد من أن MySQL يعمل في Laragon
2. تحقق من إعدادات `.env`:
```env
DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=concrete_erp
DB_USERNAME=root
DB_PASSWORD=
```

---

### المشكلة: Table not found
```
SQLSTATE[42S02]: Base table or view not found
```

**الحل:**
```powershell
# تشغيل الـ migrations
php artisan migrate

# أو إعادة إنشاء الجداول
php artisan migrate:fresh --seed
```

---

### المشكلة: Column not found
```
SQLSTATE[42S22]: Column not found
```

**الحل:**
1. تأكد من أن الـ migration شغّل
2. أو أضف الـ column يدوياً:
```powershell
php artisan make:migration add_column_to_table
```

## 6️⃣ مشاكل Authentication

### المشكلة: Unauthenticated
```
Unauthenticated.
```

**الحل:**
1. تأكد من تسجيل الدخول
2. تأكد من أن الـ session تعمل
3. تحقق من `config/auth.php`

---

### المشكلة: Password reset not working
```
Route [password.reset] not defined.
```

**الحل:**
```powershell
# إعادة نشر ملفات laravel/ui
php artisan ui:auth
```

## 7️⃣ مشاكل Session

### المشكلة: Session store not set
```
Session store not set on request.
```

**الحل:**
تأكد من أن StartSession middleware مضاف في web group:
```php
$middleware->web(append: [
    \Illuminate\Session\Middleware\StartSession::class,
]);
```

---

### المشكلة: Session expired quickly
```
Session expires too fast
```

**الحل:**
تحقق من `config/session.php`:
```php
'lifetime' => 120, // بالدقائق
'expire_on_close' => false,
```

---

## 8️⃣ مشاكل Cache

### المشكلة: Failed to clear cache
```
Failed to clear cache. Make sure you have the appropriate permissions.
```

**الحل:**
```powershell
# حذف ملفات الـ cache يدوياً
Remove-Item -Recurse -Force bootstrap\cache\* -ErrorAction SilentlyContinue
Remove-Item -Recurse -Force storage\framework\cache\* -ErrorAction SilentlyContinue
Remove-Item -Recurse -Force storage\framework\views\* -ErrorAction SilentlyContinue

# ثم
php artisan cache:clear
```

---

### المشكلة: Configuration cached
```
Configuration is cached. Changes won't take effect.
```

**الحل:**
```powershell
php artisan config:clear
```

## 9️⃣ مشاكل Excel Export

### المشكلة: ext-gd not found
```
requires ext-gd * -> it is missing from your system
```

**الحل:**
1. افتح `php.ini` في Laragon
2. أزل `;` من أمام:
```ini
extension=gd
```
3. أعد تشغيل Laragon

---

### المشكلة: ext-zip not found
```
requires ext-zip * -> it is missing from your system
```

**الحل:**
1. افتح `php.ini`
2. أزل `;` من أمام:
```ini
extension=zip
```
3. أعد تشغيل Laragon

---

### المشكلة: Export returns empty file
```
Downloaded file is empty
```

**الحل:**
تأكد من أن الـ Export class يُرجع بيانات:
```php
public function collection()
{
    return Model::all(); // تأكد من وجود بيانات
}
```

## 🔟 مشاكل الأداء

### المشكلة: Slow page load
```
Page takes too long to load
```

**الحل:**
1. فعّل OPcache
2. استخدم Eager Loading:
```php
// بدلاً من
$users = User::all();
foreach ($users as $user) {
    echo $user->company->name; // N+1 problem
}

// استخدم
$users = User::with('company')->get();
```

---

### المشكلة: Too many queries
```
N+1 Query detected
```

**الحل:**
```php
// في AppServiceProvider
public function boot()
{
    Model::preventLazyLoading(! app()->isProduction());
}
```
