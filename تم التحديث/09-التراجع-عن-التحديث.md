# ⏪ المرحلة 9: التراجع عن التحديث

## 🎯 الهدف
استعادة المشروع إلى حالته السابقة في حالة فشل الترقية.

---

## ⚠️ متى تستخدم هذه الخطة؟

استخدم خطة التراجع إذا:
- ❌ أكثر من 10% من الاختبارات فاشلة
- ❌ وظائف أساسية لا تعمل (تسجيل الدخول، إضافة بيانات)
- ❌ أخطاء كثيرة لا يمكن حلها
- ❌ المشروع غير مستقر

---

## 📋 خيارات التراجع

| الخيار | الوصف | السرعة | التعقيد |
|--------|-------|--------|---------|
| **الخيار A** | التراجع عبر Git | ⚡ سريع | سهل |
| **الخيار B** | استعادة من النسخة الاحتياطية | 🐢 بطيء | متوسط |
| **الخيار C** | إعادة تثبيت Laravel 8 | 🐢 بطيء | صعب |

---

## 🅰️ الخيار A: التراجع عبر Git (موصى به)

### الخطوة 1: التحقق من الـ Tags
```powershell
# عرض جميع الـ tags
git tag -l

# المتوقع: v1.0-laravel8-stable
```

### الخطوة 2: التراجع إلى الـ Tag
```powershell
# إلغاء التغييرات غير المحفوظة
git stash

# التراجع إلى الإصدار المستقر
git checkout v1.0-laravel8-stable

# أو إذا كنت على فرع الترقية
git checkout main
git reset --hard v1.0-laravel8-stable
```

### الخطوة 3: إعادة تثبيت الحزم
```powershell
# حذف vendor
Remove-Item -Recurse -Force vendor -ErrorAction SilentlyContinue

# تثبيت الحزم القديمة
composer install

# مسح الـ cache
php artisan optimize:clear
```

### الخطوة 4: التحقق
```powershell
# التحقق من الإصدار
php artisan --version
# المتوقع: Laravel Framework 8.x.x

# تشغيل الخادم
php artisan serve
```

## 🅱️ الخيار B: استعادة من النسخة الاحتياطية

### الخطوة 1: تحديد موقع النسخة الاحتياطية
```powershell
# عرض النسخ الاحتياطية
Get-ChildItem "C:\laragon\backups"
```

### الخطوة 2: حذف المشروع الحالي
```powershell
# إعادة تسمية المشروع الحالي
Rename-Item "C:\laragon\www\ConcreteERP" "C:\laragon\www\ConcreteERP_failed_upgrade"
```

### الخطوة 3: استعادة النسخة الاحتياطية
```powershell
# نسخ النسخة الاحتياطية
Copy-Item -Path "C:\laragon\backups\ConcreteERP_backup_[date]" -Destination "C:\laragon\www\ConcreteERP" -Recurse
```

### الخطوة 4: استعادة قاعدة البيانات
```powershell
# استعادة قاعدة البيانات
mysql -u root -p concrete_erp < "C:\laragon\backups\concrete_erp_[date].sql"
```

### الخطوة 5: التحقق
```powershell
cd C:\laragon\www\ConcreteERP
php artisan --version
php artisan serve
```

## 🅲️ الخيار C: إعادة تثبيت Laravel 8 (الملاذ الأخير)

### الخطوة 1: حفظ الملفات المهمة
```powershell
# نسخ الملفات المخصصة
Copy-Item -Path "app" -Destination "C:\temp\ConcreteERP_app" -Recurse
Copy-Item -Path "resources\views" -Destination "C:\temp\ConcreteERP_views" -Recurse
Copy-Item -Path "routes" -Destination "C:\temp\ConcreteERP_routes" -Recurse
Copy-Item -Path "database" -Destination "C:\temp\ConcreteERP_database" -Recurse
Copy-Item -Path ".env" -Destination "C:\temp\ConcreteERP_.env"
```

### الخطوة 2: إنشاء مشروع Laravel 8 جديد
```powershell
# حذف المشروع الحالي
Remove-Item -Recurse -Force "C:\laragon\www\ConcreteERP"

# إنشاء مشروع جديد
composer create-project laravel/laravel:^8.0 C:\laragon\www\ConcreteERP
```

### الخطوة 3: استعادة الملفات
```powershell
cd C:\laragon\www\ConcreteERP

# استعادة الملفات
Copy-Item -Path "C:\temp\ConcreteERP_app\*" -Destination "app" -Recurse -Force
Copy-Item -Path "C:\temp\ConcreteERP_views\*" -Destination "resources\views" -Recurse -Force
Copy-Item -Path "C:\temp\ConcreteERP_routes\*" -Destination "routes" -Recurse -Force
Copy-Item -Path "C:\temp\ConcreteERP_database\*" -Destination "database" -Recurse -Force
Copy-Item -Path "C:\temp\ConcreteERP_.env" -Destination ".env" -Force
```

### الخطوة 4: تثبيت الحزم المطلوبة
```powershell
composer require laravel/ui:^3.4
composer require laravelcollective/html:^6.4
# أضف باقي الحزم حسب الحاجة
```

### الخطوة 5: إعادة بناء المشروع
```powershell
composer install
php artisan key:generate
php artisan migrate
php artisan optimize:clear
```

## 🔄 بعد التراجع الناجح

### 1. توثيق المشاكل
سجل المشاكل التي واجهتها:
```markdown
## مشاكل الترقية - [التاريخ]

### المشكلة 1:
- الوصف: ...
- رسالة الخطأ: ...
- الحل المحتمل: ...

### المشكلة 2:
- الوصف: ...
- رسالة الخطأ: ...
- الحل المحتمل: ...
```

### 2. تنظيف Git (محلياً فقط)
```powershell
# حذف فرع الترقية الفاشل (محلي فقط)
git branch -D upgrade-to-laravel-11

# العودة للفرع الرئيسي
git checkout main
 

### 3. التخطيط للمحاولة القادمة
- راجع المشاكل التي واجهتها
- ابحث عن حلول
- خطط لمحاولة جديدة

---

## ⚠️ تحذيرات مهمة

1. **لا تحذف النسخ الاحتياطية** حتى تتأكد من استقرار المشروع
2. **وثّق كل خطوة** قمت بها
3. **اختبر جيداً** بعد التراجع
4. **لا تتسرع** في محاولة الترقية مرة أخرى
