# 📦 المرحلة 1: التحضير والنسخ الاحتياطي

## 🎯 الهدف
تحضير المشروع وأخذ نسخ احتياطية شاملة قبل البدء بالترقية.

---

## ✅ قائمة التحقق قبل البدء

- [ ] التأكد من أن PHP 8.2+ مثبت
- [ ] التأكد من أن Composer 2.x مثبت
- [ ] التأكد من أن Git مثبت ومُعد
- [ ] إغلاق جميع الاتصالات بقاعدة البيانات
- [ ] إيقاف أي عمليات cron أو queue workers

---

## 1️⃣ فحص إصدارات البرامج

```powershell
# فحص PHP
php -v
# المتوقع: PHP 8.2.x أو أعلى

# فحص Composer
composer -V
# المتوقع: Composer version 2.x

# فحص Git
git --version
```

---

## 2️⃣ النسخ الاحتياطي للملفات

### أ) نسخ المشروع بالكامل
```powershell
# إنشاء مجلد النسخ الاحتياطية
New-Item -ItemType Directory -Path "C:\laragon\backups" -Force

# نسخ المشروع بالكامل
$date = Get-Date -Format "yyyy-MM-dd_HH-mm"
Copy-Item -Path "C:\laragon\www\ConcreteERP" -Destination "C:\laragon\backups\ConcreteERP_backup_$date" -Recurse -Force

# التحقق من النسخة
Get-ChildItem "C:\laragon\backups"
```

### ب) نسخ الملفات المهمة فقط
```powershell
# نسخ ملفات التكوين
Copy-Item ".env" ".env.backup"
Copy-Item "composer.json" "composer.json.backup"
Copy-Item "composer.lock" "composer.lock.backup"
```

---

## 3️⃣ النسخ الاحتياطي لقاعدة البيانات

### باستخدام phpMyAdmin:
1. افتح phpMyAdmin من Laragon
2. اختر قاعدة البيانات `concrete_erp`
3. اضغط على **Export**
4. اختر **Custom**
5. حدد جميع الجداول
6. اضغط **Go** واحفظ الملف

### باستخدام سطر الأوامر:
```powershell
# تصدير قاعدة البيانات
$date = Get-Date -Format "yyyy-MM-dd_HH-mm"
mysqldump -u root -p concrete_erp > "C:\laragon\backups\concrete_erp_$date.sql"
```

---

## 4️⃣ إنشاء نقطة Git (محلياً فقط)

> ⚠️ **تنبيه مهم:** جميع أوامر Git تبقى **محلية فقط** - لا نرفع أي شيء على GitHub!

```powershell
# التأكد من أنك في مجلد المشروع
cd C:\laragon\www\ConcreteERP

# إضافة جميع التغييرات
git add .

# إنشاء commit قبل الترقية (محلي فقط)
git commit -m "Backup before Laravel 11 upgrade - $(Get-Date -Format 'yyyy-MM-dd')"

# إنشاء tag للرجوع إليه (محلي فقط)
git tag -a "v1.0-laravel8-stable" -m "Last stable version on Laravel 8"

# عرض الـ tags
git tag -l
 
```

---

## 5️⃣ إنشاء فرع للترقية (محلياً فقط)

> ⚠️ **تنبيه:** الفرع يبقى محلياً - لا نرفعه على GitHub!

```powershell
# إنشاء فرع جديد للترقية (محلي فقط)
git checkout -b upgrade-to-laravel-11

# التحقق من الفرع الحالي
git branch
 
```

> 💡 **نصيحة:** العمل على فرع منفصل يسمح لك بالتراجع بسهولة إذا حدثت مشاكل.

---

## 6️⃣ تنظيف المشروع

```powershell
# مسح الـ cache
php artisan cache:clear
php artisan config:clear
php artisan route:clear
php artisan view:clear

# حذف vendor (سيُعاد تثبيته)
# Remove-Item -Recurse -Force vendor

# حذف composer.lock (سيُعاد إنشاؤه)
# Remove-Item composer.lock
```

---

## 7️⃣ توثيق الحالة الحالية

### سجل الحزم المثبتة:
```powershell
# حفظ قائمة الحزم الحالية
composer show --installed > "خطة-التحديث\packages-before-upgrade.txt"
```

### سجل إصدار Laravel:
```powershell
# حفظ إصدار Laravel الحالي
php artisan --version > "خطة-التحديث\laravel-version-before.txt"
```
